# Créditos de `apps/`

Esta carpeta contiene el código fuente de las aplicaciones que FLinux-JC64 lleva preinstaladas. El código propio de este proyecto y sus adaptaciones se publican bajo **GPL-3.0** (ver `LICENSE` en la raíz del repositorio); cada componente conserva la atribución de sus autores originales.

- **FLFM, FLWriter, FLRadio y FLTV** — trabajo de **Facundo Adorno** (FLinux, https://flinux-distro.sourceforge.io/); esta distribución adapta su código a 64 bits.
- **FLWM** — **Bill Spitzak** (https://flwm.sourceforge.net/); aquí se incluye con el parche del degradado neón de FLinux-JC64.
- **FLConnect64** — proyecto FLConnect (https://github.com/jcarlosrf26/flconnect).
- **flskin** — proyecto flskin (https://github.com/jcarlosrf26/flskin).
- **Base gráfica** — X.Org Foundation (https://www.x.org/) y FLTK, sobre Tiny Core Linux (https://tinycorelinux.net/) y el kernel Linux (https://www.kernel.org/).
